## About BG-FILES

BG-FILES is a Windows application designed to make opening and extracting archives straightforward. Its minimal interface lets you choose an archive, browse its contents, set a destination, and extract your files in a few steps.

The **7-Zip extraction engine is included**, so no separate 7-Zip installation is required. Optional **VirusTotal integration** lets you look up existing reports for files inside an archive.

## Features

| Feature | What you can do |
|---|---|
| **Browse before extracting** | View the files inside an archive. |
| **Local extraction** | Choose a destination and access the extracted files with **Open folder**. |
| **Windows context menu** | Use **Open with BG-FILES**, **Extract here**, or **Analyze with VirusTotal** from File Explorer. |
| **Optional VirusTotal checks** | Select files, review available reports, and decide whether to continue. |
| **Personal API key** | Connect or edit your own key in Settings. |
| **Three languages** | Installer and application available in Italian, English, and Spanish. |
| **Default ZIP application** | Access Windows settings to choose BG-FILES as your default app. |

Recognized formats include **ZIP, RAR, 7Z, TAR, GZ, BZ2, and XZ**, alongside other extensions handled by the included engine. Support also depends on each archive’s characteristics; version 2.12 does not provide password entry for encrypted archives.

## Version 2.12 status

This README describes **BG-FILES 2.12**. Functional tests cover extraction, error handling, and interfaces in all three languages. VirusTotal integration has also been tested using simulated responses.

> [!IMPORTANT]

Automated tests do not certify every archive format, Windows version, or the availability of the VirusTotal service. See [Known issues and limitations](#known-issues-and-limitations) for details.

## Requirements

- **Windows with support for x64 applications.** The current installer does not target 32-bit Windows; ARM64 compatibility has not been verified.
- **.NET Framework 4.5 or later.**
- Administrator permissions for the standard installation.
- Enough free disk space for extracted files and any temporary data.
- An Internet connection and a personal API key **for VirusTotal checks only**.

A native macOS or Linux version is not available.

## Getting started

### Download and installation

1. Open the **Releases** section of this repository and read the notes for the version you want to use.
2. If available, download the installer attached to the release. For the version described here, the filename is **`BG-FILES-Setup-2.12.exe`**.
3. Run the installer and choose **Italiano**, **English**, or **Español**.
4. Complete the installation and open BG-FILES.
5. In the first-launch VirusTotal guide, connect your key or choose **Later**.

The **Source code** archives generated by GitHub are not application installers.

If Windows blocks installation, startup, or uninstallation, see [Windows and digital signatures](#windows-and-digital-signatures) before proceeding.

### Extract an archive

1. Open BG-FILES and select your archive, or drag it into the window.
2. Select **Contents** to view the file list.
3. Check the destination in Settings and select **Extract archive**.
4. When extraction finishes, select **Open folder**.

For quick extraction, right-click an archive in File Explorer and choose **Extract here**. On Windows 11, classic context-menu entries may appear under **Show more options**.

### Set BG-FILES as your default app

Open BG-FILES Settings and use the default-app button, then complete your selection in Windows Settings. File associations remain under your control and may be subject to your computer’s policies.

## VirusTotal integration

### Connect your API key

1. Create an account on the [official VirusTotal website](https://www.virustotal.com/).
2. Open [your API key page](https://www.virustotal.com/gui/my-apikey).
3. Copy your key into the BG-FILES first-launch guide or go to **Settings → Connect VirusTotal**.
4. To change it later, select **Edit key** in Settings.

A saved key is shown as connected. Its validity with VirusTotal is checked when you make a request to the service.

### Check files before extracting

1. Choose **Analyze with VirusTotal** in the main window or the archive’s context menu.
2. Select the files you want to check.
3. Select **Check selected**. You can cancel while the check is running.
4. Review the available results. When a usable report exists, the central button changes to **Open report** for the highlighted file.
5. Choose **Cancel extraction** or **Continue extraction**.

> [!NOTE]
> **Continue extraction extracts the entire archive**, including files you did not select for checking. The selection determines which files are checked with VirusTotal, not which files are extracted.

### Understand the results

BG-FILES calculates a **SHA-256 hash** locally for each selected file and looks up its report on VirusTotal. This retrieves existing analysis results; it does not upload file contents to request a new scan.

| Result | Meaning |
|---|---|
| **Detections** | Engines that classified the file as malicious in the available report. |
| **Suspicious** | Suspicious classifications, shown separately from detections. |
| **Engines without a result** | Engines that did not produce a usable result. |
| **Unknown file** | No report is available for that hash. |
| **Error or quota reached** | The check could not be completed; this is not a clean result. |
| **Analysis date** | The date of the retrieved report, which may be older than your lookup in the app. |

**Zero detections does not guarantee that a file is safe.** Detection counts are not a safety percentage. BG-FILES and its VirusTotal integration do not replace your antivirus software.

### Privacy and key storage

- Checks send **SHA-256 hashes** to VirusTotal without uploading file contents.
- Requests include your API key for authentication and normal connection information. A hash can identify a file already known to the service.
- Selected files are not executed during the check.
- Your key is stored in your Windows user’s local application-data folder, encrypted using **Windows DPAPI**.
- Settings can be reused after an update, so you generally do not need to enter your key again for each version.

Never include your API key in GitHub issues, screenshots, or shared files.

### Check limits

| Local limit | Version 2.12 |
|---|---|
| Individual file size for checking | 256 MiB |
| Total data checked | 1 GiB per operation |
| Archive size | 2 GiB |
| Nested archives | Their contents are not checked recursively |

VirusTotal’s Public API has usage quotas, documented as **4 requests per minute and 500 per day**. Quotas apply to the account and may also be consumed by other applications. Checking many files can take time.

Use of the integration is subject to [VirusTotal’s terms and limits](https://docs.virustotal.com/reference/public-vs-premium-api) and [API usage rules](https://docs.virustotal.com/docs/api-overview), including restrictions on commercial products and certain business workflows. BG-FILES being free and using personal API keys does not override those conditions. Specific approval from VirusTotal for this integration has not been obtained.

## Windows and digital signatures

Version 2.12 does not have a recognized digital signature. Windows may display warnings or prevent a component from running, depending on the security settings and policies in effect.

During testing of version 2.12, Windows application control blocked **`unins000.exe`**, the uninstaller. This issue remains open.

If you encounter a block, keep the warning text and report which file was involved. Do not disable Defender or Smart App Control to bypass it. Downloading the app from GitHub does not change its signature or automatically prevent these blocks.

## Known issues and limitations

- **Uninstallation:** Smart App Control may block the uninstaller; reproduced with version 2.12.
- **Concurrent requests:** In version 2.12, VirusTotal request spacing is managed per process. Multiple app instances may reach the account quota sooner than expected.
- **Compatibility:** Not every Windows version, architecture, configuration, or archive-format variant has been verified.
- **Encrypted archives:** Password entry is not available.
- **VirusTotal:** Missing, outdated, or incomplete reports and service outages may limit checks.

## Frequently asked questions

<details>
<summary><strong>Do I need to install 7-Zip separately?</strong></summary>

No. BG-FILES includes the extraction engine it needs. It uses 7-Zip technology; its decompression engine was not built from scratch for BG-FILES.

</details>

<details>
<summary><strong>Can I use BG-FILES without Internet access or an API key?</strong></summary>

Yes. Normal extraction works locally. Internet access and a personal key are required to look up VirusTotal reports.

</details>

<details>
<summary><strong>Is a file safe if VirusTotal does not know it?</strong></summary>

That result cannot establish whether the file is safe. “Unknown” means the service did not return an available report for the requested hash.

</details>

<details>
<summary><strong>How do I correct an incorrect API key?</strong></summary>

Open Settings and select **Edit key**. The VirusTotal results window is dedicated to checks and reports.

</details>

<details>
<summary><strong>Do I need to donate to use the app?</strong></summary>

No. Donations are optional and are not required to use BG-FILES.

</details>
